# Едим дома — Telegram Mini App

Статический планировщик семейного меню на неделю: параметры семьи, бюджет, исключения и техника → меню, рецепты, КБЖУ и список покупок.

- Без backend и внешней передачи данных
- Работает на GitHub Pages
- Telegram WebApp SDK + адаптивный мобильный интерфейс
- Цены явно обозначены как ориентировочные

Локальная проверка расчётного движка: `node test.js`.
